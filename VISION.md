# Superlattice Vision

Superlattice is a geometry-first engine for constructing canonical spatial models.

## Principles

1. Geometry is canonical.
2. Rendering is deterministic.
3. SVG is generated, never hand-authored.
4. Every experiment is reproducible.
5. Camera, geometry, materials, and visibility remain independent systems.

The long-term objective is a reusable geometry kernel capable of producing mathematically precise scenes and multiple rendering backends.
