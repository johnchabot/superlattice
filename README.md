# Superlattice

Superlattice is a declarative geometry engine for constructing, studying, and rendering canonical geometry.

## Philosophy

Geometry is the source of truth. Scene descriptions are canonical. SVG files are generated artifacts.

## Initial Goals

- Canonical construction plane
- Canonical hexagonal prism
- Declarative scene graph
- Deterministic SVG renderer
- Experiment-driven development

## Development Workflow

Manifest → Geometry Engine → Camera → Visibility → SVG
